# 프로토타입 가이드 — 배포 주소에서 4단계 전부 돌려보기

> 대상: 기획자·검토자. 설치·서버 없이 **브라우저만으로** 제품의 4단계를 끝까지 한 번 돌려보는 방법.

## 1. 어디로 가면 되나

**https://parkh37t.github.io/con-ai/#/prototype**

- 메인 화면의 **「4단계 전부 돌려보기」** 버튼, 또는 좌측 레일의 **둘러보기 → 프로토타입 4단계 실행** 으로도 갑니다.
- 로그인·설치·API 키가 **필요 없습니다.**
- 진행 기록·만들어진 설계서는 **이 브라우저에만** 남습니다. 다른 사람에게는 보이지 않습니다.

## 2. 무엇을 누르면 되나

화면에 단계 카드 4개가 순서대로 있습니다. 위에서부터 하나씩 버튼을 누르면 됩니다. 앞 단계가 끝나야 다음 버튼이 열립니다.

| 단계 | 버튼 | 끝나면 |
|---|---|---|
| ① AS-IS 분석 | 샘플 대상 분석 | 페인포인트 8건 → 「페인포인트 보기」 로 상세 확인 |
| ② 화면 생성 | 샘플 문장으로 만들기 | 새 화면(SCREEN-00N) revision 1 → 「설계서 열기」 |
| ③ 검토 · 수정 | 샘플 코멘트로 수정 | 코멘트 2건 반영 revision 2 → 「검토 화면에서 보기」 |
| ④ 완료 · 이관 | 완료(v1.0) 처리 | v1.0 + 산출물 6개 파일 → 「완료 화면」 |

한 번에 5~15초씩 걸립니다. 중간에 새로고침해도 진행 기록은 남습니다. 다시 처음부터 하려면 맨 아래 **「처음부터 다시」**.

## 3. 화면 링크 지도 (배포 주소)

모두 `https://parkh37t.github.io/con-ai/` 뒤에 붙입니다. 로그인 없이 바로 열립니다.

## 4. 무엇이 «진짜» 이고 무엇이 «샘플» 인가

이 구분이 이 화면의 핵심입니다. 카드마다 두 줄로 적혀 있고, 요약하면 이렇습니다.

**실제로 실행되는 것 (브라우저 안에서 진짜로 돕니다)**

- 문맥 조립 (요구사항·수용조건·참고 화면·CASE·유지 조건을 프롬프트로 묶는 것)
- 화면명세 **스키마·참조 검사** (`@con-ai/schemas`)
- HTML 목업 + 우측 설명 **렌더** (`@con-ai/renderer`)
- **V1 명세 검사 · V2 구조 검사** (`@con-ai/validators`)
- **V3 실행 검사** — 격리 iframe 에서 CASE 전환·검색 필터·다운로드·콘솔 오류를 실제로 눌러 봅니다
- **승인 게이트** — 필수 검사가 전부 pass 이고 차단 코멘트가 0 이어야 v1.0 이 됩니다
- **산출물 6개 파일** 생성 (index.html·spec·trace·validation·comments·manifest, 각 sha256 포함)
- AS-IS **페인포인트 규칙** (서버의 `MODEL_ADAPTER=fixture` 와 같은 클래스)
- ID 매핑(`#/trace`)의 커버리지 계산·번호 발번 판정

**미리 기록해 둔 것 (지금 만들지 않습니다)**

- AS-IS 대상의 **페이지 구조와 스크린샷 2장** — 브라우저는 다른 사이트를 캡처할 수 없습니다.
  `pnpm demo:snapshot` 이 서버의 실제 분석기(Playwright)로 합성 페이지를 분석해 남긴 값입니다.
- 프로젝트·요구사항·참고 화면 등 **시드 데이터**

**더미인 것**

- **화면명세를 쓰는 모델**. 기본은 더미 어댑터(fixture)로, 모델을 호출하지 않고 규칙으로 명세를 만듭니다.
  화면 위쪽에 `더미 어댑터(fixture)` 라고 적혀 있습니다.

**아직 안 되는 것 (정직하게 실패합니다)**

- **임의 URL 의 AS-IS 분석** — 실패로 끝나고 이유를 적습니다. 성공으로 위장하지 않습니다.
- **팀 공유** — 승인·발번 결과는 이 브라우저에만 남습니다. 함께 쓰는 이관 폴더(`exports/…`)는 서버 실행에서 만듭니다.

## 5. 실제 모델로 돌려보고 싶다면

좌측 아래 **자격 증명 칩**(「키 없음 — 스냅샷 데모」)을 누르고 Claude API 키(`sk-ant-…`) 또는 토큰을 넣습니다.

- 값은 **이 브라우저에만** 저장되고 `api.anthropic.com` 으로만 갑니다. 우리 서버로는 가지 않습니다.
- 넣은 뒤 다시 ② 생성을 돌리면 명세를 **모델이 직접** 씁니다. 나머지 단계는 그대로입니다.
- 화면 표시가 `fixture 더미` → `anthropic:claude-opus-5` 로 바뀝니다.

## 6. 팀이 함께 쓰려면 (서버 실행)

프로토타입은 «혼자 한 번 돌려보는» 용도입니다. 여러 사람이 같은 결과를 보고 이관 폴더를 만들려면 서버가 필요합니다.

```bash
git clone https://github.com/parkh37t/con-ai.git && cd con-ai
pnpm bootstrap        # Node 22·pnpm 확인 → 설치 → .env 생성
set -a; source .env; set +a
pnpm dev              # 웹 http://localhost:5173 , API http://localhost:8787
```

서버 실행에서 달라지는 것:

- AS-IS 분석이 **임의 URL** 을 실제로 방문해 캡처합니다.
- V3 를 Playwright chromium 으로 돌립니다(브라우저 iframe 대신).
- 승인하면 `exports/<프로젝트>/<화면>/v1.0/` 폴더에 산출물이 **파일로 저장**됩니다.
- 결과가 DB 에 남아 팀이 같은 것을 봅니다.

## 7. 자주 묻는 것

**Q. ④ 완료에서 「필수 검사 미통과」 가 뜹니다.**
V3 가 실제로 실패한 것입니다. 완료 화면의 검증 표에서 어떤 검사가 왜 실패했는지 볼 수 있습니다.
예: 표에 더미 행이 없으면 검색 필터 검사가 통과할 수 없습니다. 미실행·실패를 통과로 바꾸지 않는 것이 이 게이트의 목적입니다.

**Q. 진행 기록을 지우면 만든 설계서도 사라지나요?**
아닙니다. 「처음부터 다시」는 진행 기록만 지웁니다. 만들어진 화면·설계서까지 지우려면 자격 증명 패널의
**「브라우저 저장 데이터 지우기」** 를 씁니다.

**Q. 다른 사람에게 결과를 보여주려면?**
완료 화면에서 **산출물 파일 6개를 내려받아** 전달하거나, 서버 실행에서 완료해 이관 폴더를 공유합니다.
