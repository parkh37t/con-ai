# 지식 문서

참고자료(설계 v0.2, 검토보고서 v0.2, 개발시작 프롬프트 v0.2, 검토 CSV)를 관점별로 학습하고 반박 검증을 거쳐 정리한 문서다. 원본은 `docs/reference/` 에 있으며, 이 문서들은 요약·해석이다. 프로세스 정의가 충돌하면 `CLAUDE.md` 의 4단계 프로세스를 우선한다.

| 문서 | 내용 |
|---|---|
| `01_제품정의_사용흐름.md` | 제품 정의, 사용자·역할·승인 권한, 9단계 사용 흐름, 9개 제품 화면, 생성 작업 유형 5종, MVP 범위 |
| `02_데이터모델_ID_버전.md` | 엔터티 15종, 원본 불변·버전 원칙, 내부 UUID 와 외부 화면 ID 분리, 별칭·임시 레코드, baseline, 작업/산출물 상태 |
| `09_원본자료_검토범위_한계.md` | 원본 13개의 정체·역할, 무엇이 검증됐고 무엇이 아닌지, 개발 시 원본 취급 규칙 |
| `10_사용자역할_두축_제품역할과_업무역할.md` | 제품 사용자 역할(승인 권한)과 업무 사용자 역할(화면 이용·포털)의 분리 |

나머지 관점(매핑·추적, 프롬프트·어댑터, 명세·렌더링·S2B 프로파일, 검증·승인, 시스템 구조)은 문서 대신 코드와 스키마(`packages/schemas`, `packages/domain`, `fixtures`)의 README 와 주석에 출처를 달아 반영했다. 필요하면 학습 결과(관점별 JSON)에서 추가 문서를 만들 수 있다.
