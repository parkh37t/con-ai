5. 실행 로드맵

난이도·의존성 기준 3단계. Phase 1로 빠른 성과 → Phase 2 구조 전환 → Phase 3 마감

Phase 1 · Quick-win (0~2개월)

  • 클럽 앰버 전환 CTA를 객실·예약 화면에 삽입(#4)
  • 홈 통합 검색바 프로토타입(지역·날짜) — 결과는 기존 지점 연결
  • 핵심 페이지 OG·메타 보강(#5 일부)

Phase 2 · 구조 전환 (2~8개월)

  • 통합 예약·탐색 허브 정식 구축(#1)
  • 반응형 단일 도메인 전환, m. 단계 폐지(#2)
  • 통합 디자인시스템 + 지점 템플릿 표준(#3)

Phase 3 · 마감·고도화 (8개월~)

  • URL 현대화·구조화데이터 전면(#5)
  • WCAG 2.1 AA 접근성 인증(#6)
  • 다국어 콘텐츠 동기화·개인화 추천
