# 관리자(운영) 작업가이드 — SSOT 🟡

> 운영자 채널(호텔 백오피스) 화면을 신규/리빌드/보강할 때 따르는 정의·정책·컨벤션 **단일 출처**.
> 프론트 포털과 컴포넌트·SSOT·도메인이 다르므로 혼용 금지.
> 🟡 내용은 앰배서더 호텔 RFP 확정 후 채운다. 아래는 호텔 운영 일반 가정 + 인테이크 산출물 기반 초안.

> ★ **화면 생산 골든**: 모든 관리자 화면은 공용 `방법론/templates/template_screen.html` 복제→개조(백지 금지). 좌측 GNB/LNB는 운영 백오피스 컴포넌트로 구성.

| 대상 사용자 | 예약팀·프론트데스크·요금/레비뉴 담당·마케팅·시스템 관리자 |
| 진입점 | `화면설계/관리자/index.html` |

## 3. 업무 도메인 범위

### 책임지는 업무 (가안)
- 예약관리(조회·확정·변경·취소·노쇼 처리)
- 객실/인벤토리·요금(시즌·플랜·프로모션) 관리
- 회원·등급·포인트 운영
- 콘텐츠(객실·다이닝·시설·프로모션) 등록·전시
- 리포트(판매·점유율·매출)·CS·시스템 설정

### 책임지지 않는 업무 (프론트 영역)
- ❌ 고객 예약 진행·결제 (프론트)
- ❌ 멤버십 가입 (프론트)

## 4. 화면 ID 규칙
- `admin-<영역>-<기능>` (kebab). 예: `admin-reservation-list`, `admin-rate-calendar`.
