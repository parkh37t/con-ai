# 00_입력원본 — RFP·요구사항서·기타 입력 보관소

> **여기에 앰배서더 호텔 RFP / 요구사항 제안서 / 요건정의서를 넣으면 됩니다.**
> 와일리 OS는 이 폴더의 원본을 입력으로 받아 → 추출 → SSOT 채움 → 화면 양산까지 처리합니다.

---

## 1. 무엇을 넣나 (입력 종류별)

| 넣을 문서 | 형식 | 와일리가 채우는 곳 |
|---|---|---|
| **RFP(제안요청서)** | PDF·PPTX·DOCX | `02_SSOT/작업가이드`(범위·도메인) + `03_요구사항/요구사항_추적표`(요건 발번) |
| **요구사항 정의서/제안서** | PDF·PPTX·XLSX | `02_SSOT/작업가이드`(권한·흐름·정책) + 화면 생산 직접 입력 |
| **AS-IS 화면 캡처/와이어** | PNG·JPG·PDF | 좌측 실제 화면 목업 근거 |
| **브랜드/디자인 가이드** | PDF·이미지 | DS 톤·컴포넌트 근거 |
| **다국어/요금/객실 데이터** | XLSX·CSV | `04_공통표준/더미데이터_사전`(고정 캐스트) |

## 2. 파일 형식 주의

- **PDF·PPTX·DOCX·XLSX·이미지·HTML** → 바로 파싱(wylie-extract).
- **HWP(한글)** → 직접 파싱이 까다롭습니다. **PDF로 변환**해서 넣어주시면 깔끔합니다.
- 파일명은 자유. 가능하면 `RFP_앰배서더_v1.pdf`, `요구사항정의서_v1.xlsx`처럼 종류를 앞에.

## 3. 넣은 뒤 처리 흐름

```
00_입력원본/  (RFP·요구사항서)
   │
   ├─[wylie-extract]  요건 추출 → 03_요구사항/요구사항_추적표 + ScreenSpec JSON
   ├─[wylie-intake]   기존 IA·인벤토리·벤치마킹과 대조·보강
   ├─ 02_SSOT 작업가이드 채움   (🟡 → 확정값)
   └─[wylie-screen]   골든 복제→개조 → html-lint·마커·verify → 배포
```

## 4. 이미 확보된 인테이크 산출물 (RFP 대조용)

RFP가 들어오면 아래 기존 리서치와 **교차 검증**합니다(요건 누락·As-Is 괴리 탐지):

- `IA/as-is-ia.html` — 현재 사이트 정보구조
- `inventory/index.html` — 화면 본수 카탈로그
- `benchmark/benchmark-report.html` — 경쟁 호텔 벤치마킹·페인포인트
