# 아키텍처 표준 (L0, 옵션) — 롯데면세점

> S2B `규칙.md`의 DDD 4-layer 백엔드 표준을 이식한 골격.
> **현재 산출물은 정적 화면설계서이므로 이 문서는 옵션**이다. 실제 런타임 앱(Claude API/백엔드 연동)으로 전환할 때 활성화한다. 🟡

---

## 1. 레이어 구조

```
interfaces  → application → domain
infrastructure → domain
```

- `interfaces` : Controller / Req·Rsp DTO / Transfer
- `application` : CommandService / QueryService (트랜잭션 책임)
- `domain` : Domain Model / Repository interface / Query·Command Param·Result
- `infrastructure` : Mapper(JDBC) / Cache / External Client

## 2. 강제 규칙 (S2B 계승)

| 항목 | 규칙 |
|------|------|
| Controller 위치 | `interfaces..controller`, domain/infra 직접 호출 금지 |
| Service 위치 | `@Service`는 `application` |
| Mapper 위치 | `infrastructure.jdbc` |
| 트랜잭션 | `@Transactional`은 Application만 (interfaces 금지) |
| 주입 | 생성자 주입만 — `@Autowired` 필드주입 금지 |
| 도메인 모델 | public setter 금지 (Builder/행위 메서드 중심), JPA 어노테이션 금지(MyBatis 기준) |
| 검증 | `@RequestBody`엔 `@Valid` |
| 의존성 | 슬라이스 간 순환 의존성 금지 |

## 3. 클래스 명명 (요약)

| 객체 | 패턴 |
|------|------|
| Controller | `{Model}Controller` |
| Req/Rsp DTO | `{Action}{Model}ReqDto` / `{Action}{Model}RspDto` |
| CommandService | `{Model}CommandService` |
| QueryService | `{Model}QueryService` |
| Repository | `{Model}CommandRepository` / `{Model}QueryRepository` |
