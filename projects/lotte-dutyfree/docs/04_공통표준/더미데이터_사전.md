# 더미 데이터 사전 (L3) — 롯데면세점 🟡

> **목적**: 모든 화면설계서가 **동일한 고정 캐스트**를 사용하도록 통일. 어느 화면을 봐도 "이 화면과 저 화면이 연결됐구나"를 즉시 인지하게 한다.
> **원칙**: 새 이름/번호를 창작하지 말고 **반드시 본 문서 값을 복사**해 사용. 변경이 필요하면 본 문서를 먼저 업데이트.
> 🟡 값은 **가안(placeholder)** — 롯데면세점 PPTX/브랜드 가이드 확정 후 교체.

| 인도장 예약번호 | `PU-20260224-0001` | `PU-{YYYYMMDD}-{4자리}` |

## 3. 고정 날짜 / 기준일

- **기준일(Anchor)**: `2026-02-24 10:00:00` (모든 시나리오의 "현재 시각")
- 주문일: 기준일 / 출국일: 기준일 + 3일 / 인도일: 출국일

## 4. 고정 금액·표기 규칙

- 금액은 천단위 콤마 + 공백 + `원`. 면세가/정상가 병기 시 `정상가 ~~120,000원~~ → 면세가 96,000원`.
- 외화 병기(가안): `USD 80` 형식.

## 사용 지침
1. 화면 작성 시 본 문서를 먼저 열어 캐스트/번호/금액/날짜 확인.
2. 새 값이 필요하면 **먼저 본 문서에 등록** 후 사용. `테스트`, `홍길동2`, `12345` 즉흥 생성 금지.
