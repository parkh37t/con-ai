# 관리자(운영) 작업가이드 — SSOT 🟡

> 관리자 포털 화면을 신규/리빌드/보강할 때 따르는 정의·정책·컨벤션 **단일 출처**.
> 프론트 포털과 컴포넌트·SSOT·도메인이 다르므로 혼용 금지.
> 🟡 내용은 롯데면세점 PPTX 확정 후 채운다. 아래는 S2B 작업가이드 구조를 이식한 **틀 + 면세 운영 일반 가정**.

---

## 1. 포털 정의

| 구분 | 내용 (가안) |
|------|------|
| 미션 | 면세점 운영자가 상품·주문·회원·프로모션을 통합 관리하는 운영 콘솔 |
| 대상 사용자 | 롯데면세점 운영팀 (MD·CS·정산·시스템 관리자) |
| 사용 맥락 | 데스크탑 웹 (1280+) / 업무시간 운영 |
| 진입점 | `화면설계/관리자/index.html` (대시보드) |

## 3. 업무 도메인 범위

### 책임지는 업무 (가안)
- 상품 등록·승인·전시·카테고리/브랜드 관리
- 주문·배송(인도)·취소/환불 처리
- 회원 관리·등급·혜택
- 프로모션·쿠폰·기획전·이벤트 운영
- 통계·리포팅, CS(문의/리뷰) 관리, 시스템 설정

### 책임지지 않는 업무 (프론트 영역)
- ❌ 고객 탐색·구매 행위 (프론트)
