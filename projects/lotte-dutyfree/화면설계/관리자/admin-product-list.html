화면명상품관리
화면목적운영자가 등록 상품을 카테고리/브랜드/상태로 조회하고, 승인·노출 ON/OFF·재고를 관리하는 목록 화면. 노출중 상품이 고객 front-product-list에 표시된다.

stateDiagram-v2

  노출중 --> 숨김 : 노출 OFF

📜 정책 / 비즈니스 룰

  • 노출 동기화: '노출중' 상품만 고객 front-product-list에 표시
  • 권한: 승인·노출 변경은 MD/Super 권한(박관리=Super)
  • 품절: 재고 0 자동 품절. 재입고 시 노출중 복귀
  • 삭제 금지: 행 삭제 대신 노출 OFF(사용여부=N) — 명명규칙 §5
