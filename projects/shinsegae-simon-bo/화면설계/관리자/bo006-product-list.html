디스크립션

1검색조건

a상점 ID

  • 입력방식 text + 자동표시
  • 입력값 상점ID(6자리) → 상점명 자동
  • Default 로그인 운영자 관할 상점
  • 요소 액션 —
  • 상태 변화 —
  • 예외 처리 미존재 ID 시 "상점을 찾을 수 없습니다."

b브랜드

  • 입력방식 text + 돋보기 팝업
  • 입력값 복수선택, 콤마(,) 구분
  • Default 빈 값(전체)
  • 요소 액션 돋보기 → 브랜드 조회 팝업, 선택 시 조회조건에 콤마로 입력(예: 까날리, 울리치)
  • 상태 변화 —
  • 예외 처리 검색어 없을 시 전체 조회

c개인결제상품여부 [추가개발 3차]

  • 입력방식 radio
  • 입력값 Y / N / 전체
  • Default 전체
  • 요소 액션 신규 추가 조건
  • 상태 변화 —
  • 예외 처리 —

d카테고리

  • 입력방식 select(단계)
  • 입력값 대 > 중 > 소 > 세
  • Default 전체
  • 요소 액션 상위 선택 시 하위 동적 로드
  • 상태 변화 —
  • 예외 처리 —

e판매가·등록일자 범위

  • 입력방식 금액 range + date range
  • 입력값 원~원 / YYYY-MM-DD~
  • Default 빈 값
  • 요소 액션 —
  • 상태 변화 —
  • 예외 처리 시작 > 종료 시 "시작값은 종료값 이하여야 합니다."
2초기화/조회

f[초기화]

  • 입력방식 버튼
  • 요소 액션 모든 검색조건을 Default로 리셋
  • 예외 처리 —

g[조회]

  • 입력방식 버튼
  • 요소 액션 API 호출 → 영역4 갱신(50건/페이지)
  • 예외 처리 결과 0건 시 "조회 결과가 없습니다." · 실패 시 오류 토스트
3건수·노출

h노출건수

  • 입력방식 select
  • 입력값 20 / 50 / 100건
  • Default 50건
  • 요소 액션 변경 시 재조회
  • 예외 처리 —
4상품 목록

i상품코드(바로가기)

  • 입력방식 readonly 링크
  • 입력값 PD+일련번호
  • 요소 액션 클릭 시 개인결제→개인결제상품등록, 일반→상품등록 이동
  • 상태 변화 —
  • 예외 처리 삭제 상품 비활성

j일괄적용 영역

  • 입력방식 토글 영역 + 버튼
  • 요소 액션 [일괄적용 열기] 시 영역 노출(버튼명 '닫기'). 체크 상품에 판매기간/뱃지/재고/브랜드 일괄 반영
  • 상태 변화 적용 후 목록 재조회, 체크 유지
  • 예외 처리 재고는 옵션 없는 상품만(옵션 있으면 경고)

k상태 뱃지

  • 입력방식 readonly 뱃지
  • 입력값 승인(초록)/수정(노랑)/반려(주황)/삭제(빨강)
  • Default 서버 상태값
  • 상태 변화 상태 변경 시 자동 갱신
  • 예외 처리 —
5페이지네이션

l페이징

  • 입력방식 버튼
  • Default 1페이지
  • 요소 액션 처음/이전/다음/마지막. 현재 페이지 강조
  • 예외 처리 최대 5개 노출, 초과 시 생략

데이터 / 입력값 (API)

storeId상점ID 6자리 (필수)
brandCodes[]브랜드코드 복수 (선택)
personalPayY / N / ALL (기본 ALL)
categoryCode대>중>소>세 코드 (선택)
priceFrom/To · regFrom/To금액·날짜 범위 (선택)
pageSize / page20·50·100 (기본 50) / 정수 ≥1
응답goodsCode · goodsName · brandKo/En · personalPay · outletPrice · addDcPrice · deliveryFee · stock · saleYn · soldOutYn · badge · status · regDate

예외 / 상태별 처리

로그아웃로그아웃 배너 + 헤더 사용자 흐림. 행동 시 로그인 유도.
결과 없음"조회 결과가 없습니다." 빈 상태 + 초기화 안내.
조회 실패"조회 중 오류가 발생했습니다. 잠시 후 다시 시도해주세요." 직전 결과 유지.
재고 일괄(옵션상품)옵션 있는 상품 선택 시 경고, 옵션 없는 상품만 적용.

상품 상태(라이프사이클)

승인판매 가능 상태(몰 게시). 핵심 항목 수정 시 '수정' 전환.
수정재검수 대기. 통과 시 승인.
반려보완 요청. 사유 확인 후 재제출 또는 삭제.
삭제소프트 삭제. 목록 비활성 표시.

정책 / 비즈니스 룰

  • 가시 범위: 운영자 관할 상점의 상품만 조회.
  • 일괄적용: 저장완료·재조회 시 체크 항목 유지.
  • 재고 일괄: 옵션 없는 상품만 적용. 숫자 양수 10자리.
  • 판매기간: 시작일 ≤ 종료일(YYYYMMDD 8자리).
  • 엑셀: 현재 조회 결과 전체(페이지 미적용) 다운로드.
