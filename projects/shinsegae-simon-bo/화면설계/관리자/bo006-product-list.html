일괄적용 영역
열기닫기
개인결제상품 진입(상품코드 클릭)
일반→상품등록개인결제→개인결제상품등록
단계흐름
1검색조건 입력 → [조회] → 상품목록 그리드 표시(기본 50건/페이지)
2[일괄적용 열기] → 일괄적용 영역 노출 · 체크 상품에 판매기간/뱃지/재고/브랜드 일괄 반영 → 확인창 → 재조회
3상품코드 클릭 → 개인결제상품이면 개인결제상품등록, 일반상품이면 상품등록으로 이동
· 일괄적용 후 저장완료·재조회 시 체크했던 항목은 유지된다.
· 재고 일괄적용은 옵션 없는 상품만 적용(옵션 있는 상품 선택 시 경고).
· 판매기간 시작일 ≤ 종료일 (YYYYMMDD 8자리). 재고는 숫자 양수 10자리.

1검색 조건

a브랜드

  • 돋보기 클릭 → 브랜드 조회 팝업(복수선택). 선택 시 조회조건에 콤마(,)로 구분 입력 (예: 까날리, 울리치)

b개인결제상품여부 [추가개발 3차]

  • Y / N / 전체. 신규 추가 조건

c카테고리

  • 대 > 중 > 소 > 세 분류 단계 선택(전체 기본)

d판매가 · 등록일자 범위

  • 금액/날짜 from~to 범위 검색

2상품 목록

a상품코드(바로가기)

  • 클릭 시 개인결제상품→개인결제상품등록, 일반상품→상품등록으로 이동

b브랜드명(한글)/(영문)

  • 한글·영문 병기 표시

c일괄적용 영역

  • [일괄적용 열기] 시 그리드 축소 + 영역 노출(버튼명 '일괄적용 닫기'로 변경)
  • 판매기간·뱃지유형·일괄재고없음·브랜드 일괄 반영, 각 확인창 발생
