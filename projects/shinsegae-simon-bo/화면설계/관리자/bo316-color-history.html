디스크립션

1검색조건

a컬러

  • 입력방식 select
  • 입력값 선택/블랙/블루/기타
  • Default 선택(미지정)
  • 요소 액션 선택 시 해당 컬러 이력만
  • 상태 변화 —
  • 예외 처리 미선택 시 전체

b변경일자

  • 입력방식 date range + 빠른선택
  • 입력값 YYYY-MM-DD ~
  • Default 당일 ~ 당일
  • 요소 액션 오늘/일주일/한달/1년 클릭 시 오늘 기준 자동 설정
  • 상태 변화 —
  • 예외 처리 시작 > 종료 시 경고
2조회

c[조회]

  • 입력방식 버튼
  • 요소 액션 API 호출 → 영역4 최근순 갱신
  • 예외 처리 결과 0건 시 "조회된 데이터가 없습니다."
3건수·엑셀

d엑셀 다운로드

  • 입력방식 버튼
  • 요소 액션 조회 이력 전체 엑셀 다운로드
  • 예외 처리 0건 시 비활성
4변경 이력 목록

e컬러코드/명·HEX

  • 입력방식 readonly
  • 입력값 CL+번호 / 색상명 / #HEX·MULTI
  • Default 기준정보 값
  • 상태 변화 —
  • 예외 처리 —

f셀픽 맵핑(코드/명/사용)

  • 입력방식 readonly
  • 입력값 SC+번호 / 멀티·투명 / Y·N / '변동없음'
  • Default 맵핑 결과값
  • 상태 변화 신규 맵핑/변경 시 비고에 사유 표기
  • 예외 처리 —
5페이지네이션

g페이징

  • 입력방식 버튼
  • Default 1페이지
  • 요소 액션 처음/이전/다음/마지막
  • 예외 처리 최대 5개 노출

데이터 / 입력값 (API)

colorCode컬러코드 (선택, 미지정 시 전체)
changeFrom/ToYYYY-MM-DD 범위 (기본 당일~당일)
정렬변경일시 DESC (최근 우선)
응답colorCode · colorName · hex · sortOrder · useYn · spColorCode · spColorName · spUseYn · note · regBy/regAt · modBy/modAt

예외 / 상태별 처리

로그아웃로그아웃 배너 + 헤더 흐림. 행동 시 로그인 유도.
결과 없음"조회된 데이터가 없습니다." 빈 상태 노출.
변경 유형비고에 '셀픽 컬러 신규 맵핑' / '컬러 정보 변경' 등 사유 표기.

정책 / 비즈니스 룰

  • 조회 필수조건: 없음(미입력 시 전체 조회).
  • 정렬: 최근 데이터 우선(변경일시 내림차순).
  • 변경일자 기본값: 당일 ~ 당일. 빠른선택은 오늘 기준 자동 설정.
  • 이력 생성: 컬러 기준정보 변경·셀픽 맵핑 시 batch/운영자 단위로 이력 적재.
