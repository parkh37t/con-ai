# 공급자포털 작업가이드

> 공급자포털(`공급자포털/`) 폴더에서 화면을 신규/리빌드/보강할 때 따르는 정의·정책·컨벤션 단일 출처.
> 다른 포털(`관리자포털/`, `수요자포털/`)과 컴포넌트·SSOT·도메인이 다르므로 혼용 금지.

---

## 1. 포털 정의

| 구분 | 내용 |
|------|------|
| 미션 | 공급업체가 견적·입찰·계약·검수·지급을 일관되게 처리할 수 있는 거래 채널 |
| 대상 사용자 | 공급업체(판매자) — S2B 등록 사업자 |
| 사용 맥락 | 데스크탑 웹 우선(1280+) / 모바일 일부 안내·알림만 / 업무시간 + 마감일 야간 운영 |
| 진입점 | `공급자포털/index.html` (서브메인 = My Desk) |

## 2. 사용자 유형·권한 체계

### 역할

| 역할 | 정의 | 비고 |

| 관리자 | 사업자 1인 = 관리자 1인. 권한그룹·이용자 등록·삭제 가능 | UM-010 |

| 담당자 | 견적/입찰/계약/검수 단위 담당 지정 | 본인 담당건만 처리 |

|------|:------:|:--------------------:|

| 권한그룹 설정 | ✅ | ❌ |

## 3. 업무 도메인 범위

### 책임지는 업무

- 업체정보 등록·수정 (기본정보·업종·인증·담당자)
- **견적정보 등록**(물품/용역/공사) — 카탈로그 업로드·이미지·옵션·연관인증
- **입찰 참가** — 참가신청·입찰서 제출·정정·취소
- **수의시담 응답** — 견적서 제출 / 차수 협의
- **2인수의 안내공고 응답** — 견적서 제출
- **계약 체결** (전자서명·전자계약서)
- **검수 응답** — 검수요청·재요청·기성금 청구
- 미니샵 콘텐츠 운영 (4탭 · sell-mydesk-miniShopBasicTab~004)
- 기획전/이벤트 참여 신청
- 견적오류 신고 응답 / 이용후기·만족도 응답
- 교육연수 신청 / 1:1 문의

### 책임지지 않는 업무 (다른 포털 영역)

- ❌ 견적요청·안내공고·입찰공고 등록 (수요자포털)
- ❌ 검수 합격/불합격 판정 (수요자포털)
- ❌ 정산 마감·세금계산서 발행·부과 (관리자포털)
- ❌ 카탈로그·미니샵 승인 (관리자포털)
- ❌ 기획전 모집 공고 등록 (관리자포털)

## 6. End-to-end 업무 흐름 (공급업체 담당 구간)

```
[가입]
  업체등록(다단계: 기본·업종·인증·담당자) → 관리자 승인 → 로그인 가능

[견적정보 등록 (물품관리)]
  catalogCreate (16섹션 단일 스크롤, 거래구분 case 토글)
    → requestList(승인 신청)
    → 관리자 승인 → catalogList(승인완료) 노출
    → 수요기관 검색·비교·구매 가능

[1인수의 견적요청]
  수요기관 견적요청 등록 → 공급업체 알림
    → 견적서 제출(차수) → 수요기관 결정 → 계약

[2인수의 안내공고]
  수요기관 공고 등록 → 공급업체 알림
    → 견적서 제출 → 수요기관 비교·낙찰자 선정 → 계약

[입찰]
  수요기관 입찰공고 → 공급업체 입찰참가 신청
    → 입찰서 제출 (정정/취소 가능)
    → 개찰 → 낙찰자 선정(W-S2)
    → 낙찰 → 계약

[계약체결]
  계약상대자 결정 → 전자계약(전자서명) → 계약체결완료

[검수 응답] (260512 회의 반영)
  공급업체 [검수요청] → 수요기관 [검수합격] / [검수요청반려]
    → 검수합격 (수동 또는 15일 자동) → 즉시 기성금 청구 가능
    → 검수요청반려 → 차수 누적 [재요청 등록] 또는 조치불가 → 수요기관 변경계약 분기

[기성금 청구·지급]
  검수합격 즉시(수동/자동 무관) 기성금 청구 → 수요기관 지급요청 → 관리자 정산 → 지급완료

[미니샵·전시 참여]
  관리자 모집공고 → 공급업체 참여 신청 → 승인 → 노출
```

### 핸드오프 지점

| From | 이벤트 | To |
|------|--------|-----|
| 공급업체 | 가입 신청 | 관리자 승인큐 |
| 공급업체 | 카탈로그 등록 | 관리자 승인큐 |
| 수요기관 | 견적요청·공고 | 공급업체 알림센터 |
| 공급업체 | 견적서 제출 | 수요기관 비교·접수목록 |
| 공급업체 | 입찰서 제출 | 수요기관 개찰 |
| 공급업체 | 계약 전자서명 | 수요기관 체결 처리 |
| 공급업체 | 검수요청 | 수요기관 검수관리 |
| 검수합격(수동 또는 15일 자동) | 기성금 청구 가능 | 수요기관/관리자 정산 |

## 8. 상태값 표준 (공급업체 관점)

### 거래·운영 상태(요약)

| 도메인 | 상태값 | 비고 |
|--------|--------|------|
| 가입 승인 | 신청·검토·승인·반려·보류 | 관리자 처리 결과 수신 |
| 카탈로그 승인 | 신청·승인·반려·삭제예정·이용중 | catalogList v2 5-Radius |
| 입찰 참가 | 참가신청·제출·정정·취소·낙찰·미낙찰 | W-S1 입찰하한율 폐지 / W-S2 낙찰자 선정 |
| 견적서 제출 | 제출·정정·취소·낙찰·미낙찰 | 차수 관리 |
| 계약(S-3) | 계약대기·진행중·체결완료·종료 | 변경계약 분기 |
| 검수(S-2b 3-state) | 검수요청·검수요청반려·검수합격 | **공급업체 핵심** — 260512 회의 반영 (8→3) |
| 지급(S-4) | 지급대기·검토중·지급완료·지급취소 | 기성금 청구 후 |

### 검수 3-state 워크플로우 (필수 숙지 · 260512 회의 반영)

```
[1] 검수요청 ─→ [2] 검수요청반려 (수요기관 응답)
              │       ↓
              │       공급사가 차수 누적 신규 [검수요청] 등록 (재요청 모드)
              │       또는 조치불가 의견 → 수요기관 변경계약 진입
              │
              ↓ 수동 [검수합격] 또는 15일 무응답 자동
              [3] 검수합격 (최종, 기성금 청구 가능)
```

### 전이 규칙

- 검수합격이 최종 상태 (검수확정·검수판정취소 단계 폐지)
- 검수요청 후 15일 무응답 → 자동 검수합격 (수요기관 1회 한정 7일 연장 가능, 최대 22일)
- 재요청은 별도 상태 없이 차수 누적 신규 검수요청으로 등록
- 차수 누적 (1차, 2차, 3차 ...)
- 검수요청 회수 시 시스템 자동 생성된 납품요청도 함께 회수

## 9. 정책 요약 (공급업체 차원)

### 잠금·마감
- 입찰 마감 시각 이후 제출/정정 차단
- 검수합격이 최종 상태 (검수확정·검수판정취소 단계 폐지 — 260512 회의)
- 카탈로그 승인 대기 중 수정 시 승인 재신청

### 이력·감사
- 입찰서 정정·취소 이력 보존
- 검수 차수별 기록 영구 보존
- 추첨 결과(W-S3 동률 처리) `audit_quote_draw` 영구 보존

### 알림 발송 기준
- 신규 견적요청·공고·입찰공고: 즉시
- 검수합격/검수요청반려: 즉시
- 15일 자동 검수합격 임박 D-7 / D-1 / D-Day (260512 회의)
- 7일 연장 처리 완료
- 15일 자동 검수합격 처리 완료 (기성금 청구 안내 포함)
- 가입 승인/반려: 즉시 (이메일 + 시스템)

### 보관 기준
- 견적·계약 문서: 5년 이상
- 검수 이력: 영구
- 알림 로그: 1년

### 폐지·통일 정책 (W-S 시리즈)
- **W-S1**: 입찰하한율 폐지 (견적하한율 mng-00003 보존)
- **W-S2**: 낙찰자 결정 → 낙찰자 선정 (winnerSelectedYn / Vendor / At 데이터 모델)
- **W-S4**: 입찰 신규 5건 — bidDetailUpdate·DetailPopup·ListSearch·baseUnitPricePopup·bidDraftCreate
- **W-S5**: 견적요청 보강 정책 박스
- **W4**: catalogCreate 16섹션 / 거래구분 case 토글

### 입력 표준
- 인증번호: 0–9 + inputmode + filterAuthCode
- 사업자번호 입력 필터
- 외부 검증 실패 시 `externalValidationFailPopup` 표준 팝업
