# 수요자포털 작업가이드

> 수요자포털(`수요자포털/`) 폴더에서 화면을 신규/리빌드/보강할 때 따르는 정의·정책·컨벤션 단일 출처.
> 다른 포털(`관리자포털/`, `공급자포털/`)과 컴포넌트·SSOT·도메인이 다르므로 혼용 금지.

---

## 1. 포털 정의

| 구분 | 내용 |
|------|------|
| 미션 | 수요기관(학교·공공기관)이 견적·입찰·계약·검수·지급을 합법·투명하게 처리하는 조달 채널 |
| 대상 사용자 | 수요기관 — 시도교육청·학교·지방자치단체·공공기관 |
| 사용 맥락 | 데스크탑 웹 우선(1280+) / 학기 단위 사용 패턴 / 학교 행정망 호환 고려 |
| 진입점 | `수요자포털/index.html` (메인) |
| 폴더 구조 기준 | GNB 1Depth 단위 폴더 |

## 3. 업무 도메인 범위

### 책임지는 업무

- **견적정보 조회·비교·구매** (1인수의 견적정보)
- **1인수의 견적요청** 등록·정정·취소·낙찰자 선정
- **2인수의 안내공고** 등록·접수·낙찰자 선정
- **입찰** 공고 등록·정정·개찰·낙찰자 선정
- **계약 체결** (전자서명·전자계약서)
- **검수** 판정 (합격/불합격/판정취소/확정)
- **지급요청** (검수확정 후)
- **변경계약** 처리
- 기관정보·이용자·권한그룹 관리
- 회원가입(4-step)·로그인·인증
- 외부연계 (에듀파인·조합추천·공동인증서·정부행정코드)
- 6개 몰(공공조달·에듀테크·KC키즈·조합 등) 진입
- 1:1 문의·교육연수 신청

### 책임지지 않는 업무 (다른 포털 영역)

- ❌ 견적정보 등록·미니샵 콘텐츠 (공급자포털)
- ❌ 견적서·입찰서 제출 (공급자포털)
- ❌ 기성금 청구 (공급자포털)
- ❌ 카탈로그 승인·정산 마감 (관리자포털)
- ❌ 회원가입 승인·정지·해지 (관리자포털)

## 6. End-to-end 업무 흐름 (수요기관 담당 구간)

```
[가입 4-step]
  agree(약관) → companyRegistCreate(기관 기본·인감)
    → bankSealCreate(환불계좌·인감 — 일부 변경)
    → companyRegistDone (제출)
    → 관리자 승인 → 로그인 가능
  ※ governmentCodeCreate / Comcard 분기 (D 시리즈 정책)

[견적정보 검색·비교·구매] (1인수의 견적정보)
  buy-catalog-Main / subMain → catalogList
    → 비교(buy-compare-sticky) → catalogCompare/Print/AddPopup
    → sellerDetail → 다중장바구니 → 구매 결정 → 계약

[1인수의 견적요청]
  quoteCreate (견적요청 등록 8섹션)
    → 공급업체 알림 → 견적서 제출(차수)
    → quoteList → quoteDetailUpdate (deadline 가드)
    → 낙찰자 선정 → 계약

[2인수의 안내공고]
  noticeCreate(공고 등록) → 공급업체 응답
    → 견적서 비교 → 낙찰자 선정 → 계약

[입찰]
  bidCreate → 공급업체 입찰참가
    → 정정공고(bidDetailUpdate) / 검색(bidListSearch)
    → 단가산정(baseUnitPricePopup) / 심사방법(screeningMethod)
    → 개찰 → **낙찰자 선정**(W-S2)
    → 추첨(W-S3, 동률 N≥2) → 1순위 차순위 자동 승계
    → 계약

[견적요청 추첨 (W-S3)]
  동률 발생 → quoteSelectionDraw → CSPRNG 추첨
    → quoteSelectionDrawResult → audit_quote_draw 영구 보존

[계약체결]
  postingSellerSelectPopup(낙찰자 선정 통합)
    → SelectionTab(업체 선정/계약 진행)
    → 전자서명 → 계약체결완료

[검수 응답] (260512 회의 반영)
  검수 큐 → 검수합격(15일 자동 합격 포함) / 검수요청반려(차수 누적 재요청 또는 조치불가 → 변경계약)
    → 검수합격 즉시 기성금 청구 가능 (검수확정 단계 폐지)

[지급]
  지급요청 → 관리자 정산 → 지급완료

[6개 몰]
  Main mall-card 6개 → 각 몰 상세 → 검색·구매
```

### 핸드오프 지점

| From | 이벤트 | To |
|------|--------|-----|
| 수요기관 | 가입 신청 | 관리자 승인큐 |
| 수요기관 | 견적요청·공고·입찰공고 | 공급업체 알림센터 |
| 공급업체 | 견적서·입찰서 제출 | 수요기관 비교·접수목록 |
| 수요기관 | 낙찰자 선정 | 공급업체 알림 |
| 공급업체 | 계약 전자서명 | 수요기관 체결 처리 |
| 공급업체 | 검수요청 | 수요기관 검수 큐 |
| 수요기관 | 검수합격/검수요청반려 | 공급업체 알림 |
| 검수합격(수동 또는 15일 자동) | 기성금 청구 가능 | 관리자 정산 |

## 9. 정책 요약 (수요기관 차원)

### 잠금·마감
- 견적요청·공고·입찰 마감 시각 이후 정정/취소 차단
- 계약 전자서명 후 변경은 **변경계약** 절차로만 (잔금 신청 이전만 / 1인수의 견적정보 신용카드 case 예외)
- 검수합격 후 판정취소 불가 (검수합격이 최종 상태 — 검수확정·검수판정취소 단계 폐지)

### 이력·감사
- 입찰·정정·취소 이력 보존
- 변경계약 차수별 기록 영구 보존

### 알림 발송
- 견적요청·공고 등록: 즉시 (대상 공급업체)
- 견적서·입찰서 접수: 즉시 (수요기관)
- 낙찰/미낙찰: 즉시 (공급업체)
- 검수합격/검수요청반려: 즉시 (공급업체)
- 15일 자동 검수합격 임박 D-7 / D-1 / D-Day (양측) — 260512 회의 반영
- 7일 연장 처리 완료 (양측)
- 15일 자동 검수합격 처리 완료 (양측)

### 보관 기준
- 견적·계약·입찰 문서: 5년 이상
- 검수 이력: 영구
- 알림 로그: 1년

### 회원가입 정책 (D 시리즈)
- 약관 보기 → 자동체크
- 기관구분 라디오·지자체 유형 분기
- 검색구분 단일화
- 공장주소 / 환불계좌 / 인감 영역 일부 삭제
- 이메일 인증 5분 유효
- "등록해지" 용어 통일

### 폐지·통일 정책 (W-S 시리즈)
- **W-S1**: 입찰하한율 폐지 (3 화면 텍스트 정리, bidMinLate 잔여산출물 이전)
- **W-S2**: 낙찰자 결정 → **낙찰자 선정** (137 화면 일괄)
- **W-S3**: 견적요청 추첨 신설 (CSPRNG, 차순위 자동 승계)
- **W-S4**: 입찰 신규 4건 (정정/조회/검색/단가산정)
- **W-S5**: 견적요청 보강 14화면
- **W-S5-EXT1**: quoteList 검색 라벨 정합 5건

### 입력 표준
- 인증번호: 0–9 + inputmode + filterAuthCode
- 사업자번호·나이스·카드·정부행정코드 입력 필터
- 외부 검증 실패 시 `externalValidationFailPopup`
