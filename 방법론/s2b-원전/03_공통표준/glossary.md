- **166. 입찰공고 등록** <a id="g-166"></a> — 입찰을 위해 공고를 등록하는 행위 *(출처: S2B 업무정의)*

- **169. 입찰보증금** <a id="g-169"></a> — 입찰에 참가하는 자가 계약 체결 의사를 보증하기 위해 미리 납부하는 금액 또는 보증 *(출처: 지방계약법 제12조)*
- **170. 입찰보증보험증권** <a id="g-170"></a> — 입찰보증금을 현금 대신 보험 형태로 제출하는 보증 증서 *(출처: 지방계약법 시행령 제37조 ②)*

- **172. 입찰참가 취소** <a id="g-172"></a> — 공급업체가 입찰 참여 신청을 철회하는 행위 *(출처: S2B 업무정의)*
- **173. 입찰참가신청서** <a id="g-173"></a> — 수요기관이 발주한 입찰 또는 견적서 제출 공고에 참여하기 위해 공식적으로 제출하는 서류 *(출처: 지방계약법 시행규칙 제38조 별지서식3호)*
- **174. 입찰참가자** <a id="g-174"></a> — 입찰의 참가 자격을 가지고 입찰에 참여하는 자
- **175. 입찰참가자격** <a id="g-175"></a> — 입찰에 참여하기 위한 법령 및 공고에서 요구하는 요건을 충족한 상태 *(출처: 지방계약법 시행령 제13조)*
- **176. 입찰참가자격 제한** <a id="g-176"></a> — 부정당업자에 대해 일정기간 입찰참가를 금지하는 행정 처분 *(출처: 지방계약법 제31조)*
- **109. 부정당업자** <a id="g-109"></a> — 공공기관과의 계약에서 부정행위를 하거나 계약질서를 위반한 사업자에게 일정 기간 입찰참가를 제한하는 제재 대상이 되는 자 *(출처: 지방계약법 제31조 1항 각 호 · V0.6 수정)*
- **110. 부정행위** <a id="g-110"></a> — 입찰 등 참가 과정에서의 위법·부당 행위 *(출처: 지방자치단체 입찰시 낙찰자 결정기준)*
- **8. 개찰** <a id="g-008"></a> — 투찰이 마감된 뒤 제출된 입찰서를 확인하여 낙찰자를 결정하는 행위 *(출처: 지방자치단체 입찰 및 계약집행기준 · V1.1 수정)*

- **25. 비교견적** <a id="g-025"></a> — 제출된 복수 견적을 비교·검토하는 절차 *(출처: 지방자치단체 입찰 및 계약집행기준 · V0.6 수정)*
- **26. 견적서** <a id="g-026"></a> — 공급업체가 제시하는 가격·조건 문서 *(출처: S2B 업무정의)*
- **27. 견적요청** <a id="g-027"></a> — 수의계약 대상에 대해 수요기관이 조건·금액 등을 제시하여 견적 제출을 요청하는 서비스 *(출처: S2B 업무정의)*
- **28. 견적요청 등록** <a id="g-028"></a> — 견적요청 내용을 입력하여 시스템에 등록하는 행위 *(출처: S2B 업무정의)*
- **29. 견적요청 수정** <a id="g-029"></a> — 등록된 견적요청 내용을 변경하는 행위 *(출처: S2B 업무정의)*
- **30. 견적요청 취소** <a id="g-030"></a> — 진행 중인 견적요청을 취소하는 행위 *(출처: S2B 업무정의)*
- **31. 견적정보** <a id="g-031"></a> — 공급업체가 사전에 시스템에 등록한 물품·용역 견적서 *(출처: S2B 업무정의 · V0.6 수정)*
- **32. 견적제출** <a id="g-032"></a> — 수의계약을 위해 견적서를 제출하는 행위 *(출처: 지방자치단체 입찰 및 계약집행기준 · V1.1 수정)*
- **139. 수의계약** <a id="g-139"></a> — 특정한 업자와 계약이 가장 유리하다고 판단될 때 경쟁 없이 특정인과 계약을 체결하는 방식 *(출처: 지방계약법 시행령 25조)*
- **140. 수의시담 요청** <a id="g-140"></a> — 수요기관이 수의계약 대상자에게 원 견적·계약 금액 대비 변경 희망 금액과 사유를 제시하는 행위. 수의시담 상태값: **요청중 · 검토중 · 답변 · 요청 만료 · 취소** (5종, 260518 답변 통합) *(출처: S2B 업무정의)*
- **141. 수의시담 답변** <a id="g-141"></a> — 공급업체가 수요기관의 수의시담 요청에 대해 제시하는 회신 금액(필수)과 비고(선택). 과거 '승인/반려' 두 분기를 **[답변] 단일 액션**으로 통합(260518). 답변 등록 시 견적서가 [답변] 금액으로 자동 업데이트, 1인수의 견적정보는 답변일+14일로 유효기간 갱신 *(출처: S2B 업무정의)*
- **142. 수의시담 라벨 — 기존 / 요청 / 답변** <a id="g-142"></a> — 수의시담 표·셀 내부 적층 표기에서 사용하는 3종 라벨. **[기존]** = 원 견적·계약 금액 / **[요청]** = 수요기관이 요청한 금액(과거 '희망') / **[답변]** = 공급업체가 회신한 금액(과거 '반려'). 260518 라벨 통일 *(출처: S2B 업무정의)*
- **144. 안내공고** <a id="g-144"></a> — 2인 이상으로부터 견적서를 받아 수의계약 대상자를 선정하는 경우 이용하는 S2B 서비스 *(출처: S2B 업무정의 / 지방자치단체 입찰 및 계약집행기준)*
- **145. 안내공고 등록** <a id="g-145"></a> — 2인 이상 대상 계약 안내공고를 등록하는 행위 *(출처: S2B 업무정의)*
- **146. 안내공고 마감** <a id="g-146"></a> — 안내공고 접수를 종료하는 행위 *(출처: S2B 업무정의)*
- **147. 안내공고 수정** <a id="g-147"></a> — 안내공고 내용을 수정하는 행위 *(출처: S2B 업무정의)*
- **116. 서비스 종류** <a id="g-116"></a> — S2B에서 계약상대자 선정을 위해 제공하는 조달 절차의 유형으로, 계약 방식과 진행 절차를 규정하는 단위. **1인수의 견적정보 / 1인수의 견적요청 / 2인수의 안내공고 / 입찰** 로 구분 *(출처: S2B 업무정의)*

## §4 계약

- **34. 계약** <a id="g-034"></a> — 수요기관(지방자치단체)이 공사·물품·용역을 공급받기 위해 업체와 체결하는 법적 약정
- **35. 계약 종료 처리** <a id="g-035"></a> — 계약 전 단계가 완료되어 종료 처리하는 행위 *(출처: S2B 업무정의)*
- **36. 계약 체결 취소** <a id="g-036"></a> — 체결 전 계약 진행을 중단하는 행위 *(출처: S2B 업무정의)*
- **37. 계약금액** <a id="g-037"></a> — 수요기관과 공급업체가 체결한 계약서에 명시된 총 계약가격으로 이용수수료 산정의 기준이 되는 금액 *(출처: S2B 이용수수료부과지침(2024.06.01))*
- **38. 계약내용 변경** <a id="g-038"></a> — 체결된 계약의 내용을 변경하는 행위 *(출처: S2B 업무정의)*
- **39. 계약담당자** <a id="g-039"></a> — 지방자치단체의 장으로부터 계약 사무를 위임이나 위탁받은 자 *(출처: 지방계약법 제5조 · V0.6 수정)*
- **41. 계약방법** <a id="g-041"></a> — 일반경쟁·제한경쟁·지명경쟁·수의계약 등 계약 체결 방식의 구분 *(출처: 지방계약법 시행령 제3조~제25조)*
- **42. 변경계약** <a id="g-042"></a> — 이미 체결된 계약의 일부 내용(조건, 범위, 금액, 기간 등)을 당사자간 합의로 수정하는 행위. **시점 제한**: 원칙적으로 **잔금 신청 전까지만** 가능. 예외 — **1인수의 견적정보 신용카드(선불·후불) 계약**은 계약완료(검수종료 + 결제완료) 상태에서도 가능. 변경계약 후 변경전 검수데이터는 삭제되며, 종료된 계약은 검수 재진행하지 않음.
- **43. 계약변경조서** <a id="g-043"></a> — 계약 변경 사항을 기록한 공식 문서 *(출처: 지방계약법 시행규칙 제13조)*
- **44. 계약보증금** <a id="g-044"></a> — 계약을 성실히 이행하겠다는 것을 담보하기 위해 미리 제공하는 금액 또는 보증 *(출처: 지방계약법 시행령 제51조)*
- **45. 계약상대자** <a id="g-045"></a> — 지방자치단체와 계약을 체결하는 상대방 *(출처: 지방계약법 전반)*
- **46. 계약상대자 결정** <a id="g-046"></a> — 계약 체결 대상자를 최종 확정하는 절차 *(출처: 지방자치단체 입찰 및 계약집행기준)*
- **47. 계약상식 TIP** <a id="g-047"></a> — 계약 업무를 처음 접하는 사용자를 위해 기본 개념을 설명한 안내 콘텐츠 *(출처: S2B 업무정의 · V0.6 추가)*
- **48. 계약서** <a id="g-048"></a> — 계약 조건·권리·의무를 명시한 공식 문서 *(출처: 지방자치단체를 당사자로 하는 계약에 관한 법률)*
- **49. 계약서 작성** <a id="g-049"></a> — 계약 내용을 계약서 형태로 작성하는 행위 *(출처: S2B 업무정의)*
- **50. 계약이행** <a id="g-050"></a> — 계약상대자가 계약 내용을 이행하는 행위 *(출처: 지방계약법 제15조)*
- **51. 계약이행기간** <a id="g-051"></a> — 계약상대자가 계약을 이행해야 하는 기간 *(출처: 지방계약법 시행령 제55조)*
- **52. 계약이행보증** <a id="g-052"></a> — 계약 이행을 담보하기 위해 제공되는 보증 *(출처: 지방계약법 제15조)*
- **53. 계약이행보증금** <a id="g-053"></a> — 계약 이행을 담보하기 위해 낙찰자가 납부하는 금액 또는 보증
- **54. 계약이행보증보험증권** <a id="g-054"></a> — 계약이행보증금을 보험증권으로 갈음한 경우의 증빙 문서
- **55. 계약조건 확인** <a id="g-055"></a> — 계약 조건을 검토·확인하는 행위 *(출처: S2B 업무정의)*
- **58. 계약집행기준** <a id="g-058"></a> — 지방자치단체의 입찰·계약·집행의 전반에 적용되는 기준을 정한 예규 *(출처: 지방자치단체 입찰 및 계약집행기준)*
- **59. 계약체결** <a id="g-059"></a> — 계약 조건에 합의하여 계약을 성립시키는 절차 *(출처: 지방자치단체 입찰 및 계약집행기준)*
- **61. 계약해제** <a id="g-061"></a> — 계약 성립 후 효력을 소급하여 소멸시키는 것 *(출처: 지방계약법 제30조2)*. **시점 제한**: 원칙적으로 **잔금 신청 전까지만** 가능. 예외 — **1인수의 견적정보 신용카드(선불·후불) 계약**은 계약완료 상태에서도 가능 (수요기관만 진입, 공급업체 페이지 불가, 사유 입력 필수, KCP 승인취소 호출 + 이력관리).
- **62. 계약해제통지서** <a id="g-062"></a> — 계약 해제 사실을 통지하기 위한 문서 *(출처: 지방계약법 시행규칙 제91조)*
- **63. 계약해지** <a id="g-063"></a> — 계약 효력을 장래를 향해 소멸시키는 것 *(출처: 지방계약법 제30조2)*. **시점 제한**: 원칙적으로 **잔금 신청 전까지만** 가능. 예외 — **1인수의 견적정보 신용카드(선불·후불) 계약**은 계약완료 상태에서도 가능 (수요기관만 진입, 공급업체 페이지 불가, 사유 입력 필수, KCP 승인취소 호출 + 이력관리).
- **64. 계약해지통지서** <a id="g-064"></a> — 계약 해지 사실을 통지하기 위한 문서 *(출처: 지방계약법 시행령 제91조)*
- **65. 계약현황** <a id="g-065"></a> — 진행 중이거나 완료된 계약 상태를 확인하는 메뉴 *(출처: S2B 업무정의 · V0.6 추가)*
- **188. 전자계약 체결** <a id="g-188"></a> — 전자서명을 통해 계약을 체결하는 행위 *(출처: 지방계약법 제14조)*
- **189. 전자계약서** <a id="g-189"></a> — 전자문서 형태로 체결된 계약서 *(출처: 지방계약법 제14조)*
- **192. 전자조달** <a id="g-192"></a> — 물품의 구매 또는 제조, 공사, 용역 등을 전자적 시스템을 통해 조달하는 방식 *(출처: 지방계약법시행령 제6조의2)*
- **220. 청렴서약서** <a id="g-220"></a> — 계약의 투명성 및 공정성을 높이기 위하여 입찰참가자 또는 수의계약 상대자에게 제출하도록 한 청렴한 태도로 계약을 이행하겠다는 것을 서약한 문서 *(출처: 지방계약법 제6조의2)*
- **6. 감독** <a id="g-006"></a> — 계약 이행 과정에서 수행되는 관리·감독 행위 *(출처: 지방계약법 제17조)*
- **195. 제출서류 확인** <a id="g-195"></a> — 제출된 계약 관련 서류를 확인하는 행위 *(출처: S2B 업무정의)*
- **245. 계약유형** <a id="g-245"></a> — 거래구분(물품·공사·용역)과 가격산정방식(단가·총액)을 결합한 계약 분류 단위. S2B 운영 분류 기준 통상 4종: **단가계약 / 총액계약 / 공사계약 / 용역계약**. 통계·고시금액·견적요청·연계 인터페이스 등에서 계약 분류 컬럼·필드명으로 사용 *(출처: S2B 업무정의 · V1.1 신규 등재 — 화면 정착 용어를 사전 일관성 차원에서 신규 정의)*
- **246. 계약가격방식** <a id="g-246"></a> — 계약금액 산정 기준 방식. **단가** (단위 수량당 가격×최종 수량) / **총액** (총괄 금액 일시 산정). 거래구분(물품·공사·용역)과 별개 차원의 분류 *(출처: S2B 업무정의 · V1.1 신규 등재)*

- **14. 검수 결과 등록** <a id="g-014"></a> — 검수 결과를 시스템에 등록하는 행위 *(출처: S2B 업무정의)*
- **15. 검수 반려 처리** <a id="g-015"></a> — 검수 결과 부적합 시 반려하는 행위 *(출처: S2B 업무정의)*
- **16. 검수 수행** <a id="g-016"></a> — 계약 이행 결과를 확인·검사하는 절차 *(출처: S2B 업무정의)*
- **17. 검수결과서** <a id="g-017"></a> — 검사 결과를 기록한 공식 문서 *(출처: S2B 업무정의)*
- **18. 검수관리** <a id="g-018"></a> — 계약 이행 결과에 대한 검수 업무를 처리하는 메뉴 *(출처: S2B 업무정의 · V0.6 추가)*

| 2 | **검수요청 반려** <a id="g-s2b-002"></a> | 수요기관이 검수 결과 부적합 또는 요청 자체 부적절로 반려. 공급업체는 보완 후 다시 [검수요청] 등록 (차수 누적 — 별도 "재검수요청" 상태 없음) |
| 3 | **검수합격** <a id="g-s2b-003"></a> | 수요기관 검수 결과 적합 판정(또는 15일 자동 검수합격). 공급업체 기성금 청구 가능. **최종 상태** (검수확정 단계 없음) |

#### S-2b 부속 정책

- **15일 자동 검수합격**: 검수요청 후 수요기관 응답 없이 15일 경과 시 자동으로 검수합격 처리. 직접 [검수합격] 클릭과 동등.
- **자동 검수합격 연장**: 만료 전 알림(D-7 / D-1 / D-Day 푸시 + 로그인 팝업) 노출. 수요기관 담당자 **1회 한정 7일 연장** 가능 (최대 22일까지 유예).
- **차수 관리**: 검수요청반려 후 공급업체가 다시 [검수요청] 등록할 때마다 차수 누적 (v1, v2, v3 ...). 동일 행 정보 업데이트 — 행 추가 아님.
- **변경계약 연계**: 검수합격 누적이 부족(공급업체 조치불가 등) 시 변경계약 절차로 분기.
- **유효 검수요청**: 검수요청 반려 건 제외한 모든 검수요청 (자동 합격 대상 포함).
- **검수합격금액 합산**: 차수별 지급 금액 산정·검수종료 판단의 기준이 되는 데이터 필드. 검수종료 정의 = 검수합격금액 합산 = 계약금액.
- **검수요청금액 합산**: 공급업체가 누적 요청한 금액. 단순 누적 표기용 (실효 기준은 검수합격금액 합산).
- **부분 검수 폐지**: 물품별 합격/불합격(교환·반품) 라디오 폐지. 차수 단위 통 합격 또는 반려만 사용.
- **검수방법 단일화**: 샘플검사/기능검사/완본검사 라디오 폐지. 모든 검사는 **전수검사**.
- **납품요청 자동 생성**: 공급업체가 [검수요청] 등록 시 해당 차수 납품요청이 없으면 시스템 자동 생성 + 승인 skip. 자동 생성된 납품요청은 검수요청 회수 시 함께 회수. 자동·수동 모두 공급업체 수정 불가, 수요기관만 수정 가능.

#### 매핑: S-2 ↔ S-2b

| S-2 (4-state) | S-2b (3-state) |
|:---|:---|
| 검수대기 | 검수요청 |
| 검수중 | 검수요청 (대응 진행 중) |
| 검수완료 | 검수합격 (수동 또는 15일 자동) |
| 검수반려 | 검수요청 반려 |
