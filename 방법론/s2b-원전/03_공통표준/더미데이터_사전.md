# S2B 리뉴얼 프로토타입 — 더미 데이터 사전

> **목적**: 모든 프로토타입 화면이 **동일한 고정 캐스트**를 사용하도록 통일. 어느 화면을 봐도 "아 이거 저 화면과 연결된 거구나" 를 즉시 인지할 수 있게 하기 위함.
>
> **원칙**: 신규 화면을 작성할 때 새로운 이름/번호를 창작하지 말고 **반드시 이 문서의 값을 복사해 사용**한다. 변경이 필요하면 본 문서를 먼저 업데이트.

## 9. 사용 지침

### 9.1 화면 작성 시

1. 우선 본 문서를 열어 해당 화면에 필요한 캐스트/번호/금액/날짜를 확인
2. 새로운 값을 만들고 싶으면 **먼저 본 문서에 등록**한 후 사용
3. 절대 즉흥적으로 `홍길동2`, `테스트업체`, `12345` 같은 creative 값 생성 금지

### 9.2 본 문서 업데이트 시

1. 신규 캐스트/번호 추가 시 기존 값과 충돌하지 않는지 확인
2. 변경 사항은 해당 섹션 하단에 "변경 이력" 부기
3. 변경 후 영향받는 화면 목록을 같이 관리

### 9.3 예외

- 다수 공급업체 비교 (5개 이상) 가 필요한 통계/리포트 화면은 본 문서의 기본 + 대체 A/B/C 를 순환 사용
- 대량 데이터 목록 화면은 본 문서 값으로 상위 4~5건만 채우고 나머지는 `…` 처리
