# 입력 필드 컴포넌트 정책 (L3)

> S2B `input-field-policy.md`를 이식. **도메인 무관 공용 표준**이므로 그대로 사용한다.

## 1. 입력 필드 타입별 정의

| 타입 | 최대 길이 | 허용 문자 | 비고 |
|------|----------|-----------|------|
| 일반(Text) | 200 byte | 국·영·숫·공백·특수 | 스크롤 없음 |
| 숫자(일반) | 12 byte | 숫자만 | |
| 숫자(소수점) | 16 byte | 숫자·소수점 | |
| Textarea | 500 byte | 국·영·숫·공백·특수 | 세로 스크롤만 |
| 전화/휴대폰 | 9~11 byte | 숫자만 | 하이픈 자동 삽입 (`000-0000-0000`) |
| 통화(일반) | 12 byte | 숫자만 | 3자리 콤마 자동 (`999,999,999,999`) |
| 통화(소수점) | 16 byte | 숫자·소수점 | 콤마 자동 + 소수 최대 3자리 |
| 날짜 | 8 byte | 숫자만 | `YYYY-MM-DD`, 구분자 자동, 달력 UI |
| 시간 | 6 byte | 숫자만 | `HH:MM:SS` 24h, 시계 UI |
| 에디터 | 5,000 byte | 국·영·숫·공백·특수 | WYSIWYG |

## 2. 입력 가능 범위 정책
- 필드별 **byte 기준** 제한. 허용 문자 외 입력 **실시간 차단**. 별도 정의 시 화면에서 명시.

## 3. 유효성 체크 (Validation)

| Fail Type | 설명 |
|-----------|------|
| TYPE-A | 필드 하단에 에러 메시지 노출 |
| TYPE-B | 별도 영역 표시(스타일/위치 정책 다름 가능) |

- 에러 메시지: `$error_message$` 형태, Placeholder와 별도 노출.

## 4. 유효성 노출 시점
1. 필드 **포커스 아웃** 시 (개별 검증)
2. **등록 버튼 클릭** 시 (전체 일괄 검증)

## 5. 공통 입력 UX
- 자동 포맷팅: 전화(하이픈)·금액(콤마)·날짜/시간(구분자) 필수.
- 스크롤: 일반 입력 없음 / textarea 세로만.

## 6. 핵심 요약
| 항목 | 내용 |
|------|------|
| 입력 제한 기준 | 모든 필드 byte 기준 |
| 허용 문자 | 타입별 엄격 분리 |
| 자동 포맷팅 | 필수 적용 |
| 유효성 체크 | 포커스 아웃 + 저장 시 2단계 |
| 에러 메시지 | 필드 단위 노출 |

> 면세 도메인 특수 입력(여권번호·출국정보·외화 등)은 화면별 별도 정의로 추가한다. 🟡
